Module 01 / Vibe coding

What is vibe coding (and who cares?)

You describe, the AI builds, you check.

Read

1.1 Two definitions

The short definition: vibe coding is building software with the help of AI. The long definition: vibe coding is directing capable AI agents as they plan, write, test and deploy code for you. An AI agent is an AI that does not only answer; it makes a plan, takes several steps on its own, and reports back.

Most of it is a conversation: you say what you want in everyday language, the AI writes the Python, and you say what to change. Success depends on how clearly you communicate and how much context you give, not on knowing syntax.

Read

1.2 Most of the work, not all of it

The AI does perhaps 80 to 90 percent of the work. The rest is yours, and it is why this course exists:

The AI is good at You still own
Writing code that runs Deciding what to build and for whom
Explaining code and error messages Checking the result is right, not only that it runs
Doing setup steps Keeping secrets such as API keys safe
Trying again when something fails Saving your work and putting it online

1.3 Why it matters now

Speed: an app that once needed a team and months can be built by one person in hours. Who can build: if you can describe a problem clearly, you can solve it with a small tool of your own, such as turning a weekly spreadsheet chore into a web page.
