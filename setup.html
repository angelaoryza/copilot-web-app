Before you arrive

Set up before you arrive

Do this a day or two before the meetup, so the three hours go to building.

Step 1

P.1 Install VS Code

Do it download VS Code from code.visualstudio.com.

  • Windows: run the installer with the default options.
  • Mac: drag Visual Studio Code into Applications.
Step 2

P.2 Install Python

Do it download Python 3.10 or newer from python.org/downloads.

  • Windows: on the first screen, tick Add python.exe to PATH, then Install Now.
  • Mac: open the .pkg file and follow the steps.

Check it: in a terminal, python --version (Windows) or python3 --version (Mac) shows Python 3.…

Step 3

P.3 Install Git

  • Windows: download it from git-scm.com/downloads and keep the defaults.
  • Mac: type git --version in Terminal. If Git is missing, click Install when your Mac offers the developer tools.

Check it: git --version shows a version number.

Step 4

P.4 Create your accounts

Account Where For
GitHub github.com/signup Copilot, and storing your code
Copilot github.com/settings/copilot Turn on Copilot Free
Sectors sectors.app Live IDX data and your API key
Streamlit Community Cloud share.streamlit.io Putting your app online; sign in with GitHub

Use the same GitHub account everywhere.

Step 5

P.5 Install GitHub Copilot and Python in VS Code

Do it

1

Open Extensions in the left bar (Ctrl+Shift+X, Mac Cmd+Shift+X).

2

Install GitHub Copilot.

3

Install Python by Microsoft.

4

Click the Accounts icon at the bottom left and sign in with GitHub.

Check it: open Copilot Chat (chat icon, title bar) and send Hello. No answer? In Extensions, click GitHub Copilot → Enable.

Step 6

P.6 Get the starter files

Starter kit on GitHub Download from Google Drive
  • New to GitHub: download the ZIP from Google Drive, unzip it (Windows: right-click → Extract All), then File → Open Folder in VS Code.
  • Familiar with GitHub: click Use this template → Create a new repository, then clone your copy with Git: Clone from the Command Palette (Ctrl+Shift+P). In Module 8, skip 8.3 and the publish step in 8.5.
Step 7

P.7 Create a virtual environment

A virtual environment is a private box of packages for one project, kept in a .venv folder.

Easy way (Windows and Mac).Do it press Ctrl+Shift+P (Cmd+Shift+P), run Python: Create Environment, choose Venv, pick your Python, tick requirements.txt, click OK.

Terminal way. If that fails, open Terminal → New Terminal and run:

Windows (PowerShell)
# Create the box
python -m venv .venv
# Turn it on
.venv\Scripts\activate
# Install the packages
pip install -r requirements.txt
Mac (Terminal)
# Create the box
python3 -m venv .venv
# Turn it on
source .venv/bin/activate
# Install the packages
pip install -r requirements.txt
Windows tip If “running scripts is disabled”, run Set-ExecutionPolicy -Scope CurrentUser -ExecutionPolicy RemoteSigned, answer Y, and try again.
Step 8

P.8 Check that it works

Do it open a new terminal and run:

Terminal
streamlit run app.py

A page titled IDX Stock Snapshot opens in your browser. Press Ctrl+C to stop it. If streamlit is not found, open a new terminal and try again.
