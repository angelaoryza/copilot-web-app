10.1 MCP: a USB port for AI tools

USB made one plug fit every printer, mouse and camera. The Model Context Protocol (MCP) does that for AI tools: a service such as Sectors publishes an MCP server, and any AI tool that speaks MCP, including Copilot in Agent mode, can plug in. The server offers tools: named actions such as “fetch top gainers”.

10.2 What changes when the AI can call tools

Without tools, Copilot can only guess at today’s prices from months-old training. With the Sectors MCP server it fetches live data, then reasons about it. It asks before calling a tool, shows the inputs, and each call spends credits. Still check the answer, including its date.

10.3 Instructor demo

Watch

The instructor has the Sectors MCP server connected in VS Code and sends, in Agent mode:

Prompt (instructor demo)
Top IDX gainers this week?

Use the Sectors tools. Show the top five over the last 7 days among companies worth more than Rp 5 trillion, as a table with ticker, company name and percent change. Tell me the date the data is as of.
What to notice
  • Copilot picks a Sectors tool for top movers by itself, and asks before it runs it
  • The tool’s inputs: a 7-day period, top gainers, five stocks, a minimum company size
  • The answer gives a date: the data is from the last trading day, not “now”
  • Percent changes are formatted correctly, for example 0.153 shown as 15.3%
  • A follow-up such as “Show the closing prices of the top one for the last 30 days” triggers a second tool call

10.4 Set it up at home

The Sectors MCP server lives at https://sectors-mcp.supertype.ai/mcp, and it signs you in with your Sectors API key.

Do it

In your project, create a folder .vscode with a file mcp.json inside, and paste:

.vscode/mcp.json
{
  "servers": {
    "sectors": {
      "type": "http",
      "url": "https://sectors-mcp.supertype.ai/mcp",
      "headers": {
        "Authorization": "Bearer ${input:sectors-api-key}"
      }
    }
  },
  "inputs": [
    {
      "type": "promptString",
      "id": "sectors-api-key",
      "description": "Your Sectors Financial API key",
      "password": true
    }
  ]
}

Save it, and start the server from the Start link VS Code shows above "sectors". VS Code asks for your key the first time the server starts and does not keep it after a restart, so the key never sits in the file. Then ask a question in Agent mode, such as the one in 10.3.
