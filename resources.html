Appendix

Glossary

Term Meaning
Agent mode The Copilot mode that builds: it creates and edits files, runs commands and tries again (2.3).
AI agent An AI that plans and takes several steps on its own instead of only answering.
API Application programming interface: a set way for one program to ask another for data (5.1).
API key A secret code that identifies you to an API; each request with it may use credits (5.2).
Ask mode The Copilot mode that answers and plans without changing files (2.3).
Backend The part of an app that works out of sight: formulas, rules, fetching data, keeping secrets (3.3).
Bug The app doing something wrong, from a crash to a wrong number.
Closing price The price of one share at the end of a trading day.
Commit A save point in Git, with a short message about what changed (8.1).
Context Everything Copilot sees when it answers: your prompt, attached files, the chat so far.
Credits The units Sectors counts API requests in.
Data Where an app’s numbers come from: what you type, or an API (3.3).
Deploy Copying your app to a server so it is live on the internet (9.1).
.env A local file that holds secrets as NAME=value lines; never committed (5.3).
Framework A ready-made starter kit of code; Streamlit is one.
Frontend The part of an app you see and click (3.3).
Git A free tool that keeps a history of your project as commits (8.1).
GitHub A website that stores Git repositories online.
.gitignore A list of files Git must never save (8.2).
Helper A small file of ready-made functions; sectors.py is one (5.1).
Host A service that stores, builds and serves your app (9.1).
IDE Integrated development environment: a code editor with extra tools.
IDX The Indonesia Stock Exchange.
JSON A text format for data made of labelled values, such as "sector": "Financials".
Localhost Your own computer, as an address: http://localhost:8501 for a Streamlit app.
Lot The unit IDX shares are bought in: 100 shares.
Market cap Market capitalisation: share price × number of shares, in rupiah.
MCP Model Context Protocol: a standard plug that lets AI tools use outside services (10.1).
Native app An app installed on one operating system, such as a phone app.
Plan → Implement → Test → Repeat The four-step loop for building every feature (4.1).
Push Uploading your commits to GitHub (8.5).
Repository (repo) A project folder together with its full Git history.
requirements.txt The list of Python packages an app needs; the host installs them.
Secret A value that must not be shared, such as an API key or password.
Secrets (Streamlit) Where a deployed app’s secrets live on Streamlit Community Cloud (9.3).
Server A computer in a data centre that keeps an app running for everyone.
Stage Choosing which changes go into the next commit (8.1).
Streamlit A Python framework that turns a script into a web app.
Streamlit Community Cloud Streamlit’s free host for public apps.
Terminal A text window where you type commands.
Ticker A stock’s short code on the exchange, such as BBCA or TLKM.
Volume The number of shares traded in a day.
Web app An app that runs in a browser and is opened with a link (3.2).
