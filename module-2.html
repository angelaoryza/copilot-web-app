2.1 The tools are chosen for you

Choosing tools can eat a whole weekend. The tools matter less than momentum: the best stack is the one you actually open and use. Today’s is chosen for you, so you can start building now:

Job Today’s tool

Area Where What you use it for

2.3 Ask and Agent

At the bottom of the Copilot Chat box is a picker that sets the mode. Today you use two:

Mode What it does Use it when
Ask Answers, explains and plans; never changes your files You want to understand something or plan a feature
Agent Works in several steps: creates and edits files, runs commands, reads errors, tries again You want something built or changed

A simple rule: Ask to think, Agent to do. When Agent finishes, read its summary to see which files it changed. If Agent asks permission to run a command in the terminal, allow it only if you understand what it does.

Hands-on

2.4 Try Ask mode

Do it switch Copilot Chat to Ask and send:

Prompt
I’m brand new to this project. Look at the files and folders in this project and tell me what each one is for, in one short bullet point each. Don’t change anything.
What to look for

a bullet for each file and folder, including app.py (almost empty) and sectors.py (the helper that gets stock data); no file changed in the Explorer.

Hands-on

2.5 Try Agent mode with a lazy prompt

Now see what Agent does when you give it almost nothing to go on.

Do it click New Chat (+), switch to Agent, and send:

Prompt
Create a web for investment calculator

Watch it work. It plans, creates one or more files, and may ask to run a command. When it stops, read its summary and answer these questions:

Question What Agent probably did
Which files did it create or change? Picked file names itself, maybe even rewrote app.py
What does the calculator calculate? Chose its own formula: savings, a loan, or something else
What inputs and currency does it use? Guessed, often in dollars rather than rupiah
What kind of web page is it? Picked its own tools, maybe plain HTML instead of Streamlit
What to look for

something that probably works, built from guesses. Agent made every decision because you made none. Now put your folder back: in the same chat, send Undo everything you just did and put the project back exactly as it was. Check that the files Agent created are gone and that app.py again only shows the title IDX Stock Snapshot.

The lesson: Agent is powerful but cannot read your mind. To make those decisions yourself, you need to know what a web app is made of. That is the next module.
