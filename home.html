Introduction

Overview

In three hours you build one web app on live Indonesia Stock Exchange (IDX) data and put it online. No programming experience needed: you describe what you want, GitHub Copilot writes the code, and you check what comes back.

You will learn to:

  • Plan with Copilot’s Ask mode and build with Agent mode
  • Build in small loops: Plan → Implement → Test → Repeat
  • Connect your app to live IDX data with the Sectors API, keeping your key safe
  • Save your work to GitHub and share a live link
